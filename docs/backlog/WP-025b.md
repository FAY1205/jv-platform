# WP-025b: Trusted device (AUT-10) + ACC-02 sessions registry
Spec: AUT-10, ACC-02 · Phase: 2 · Tier: A · Depends: WP-025a, WP-007 (refresh.ts)
## Goal
"Remember this device" lets a partner skip OTP for 30 days via an app-owned rotating
refresh token (reuse ⇒ revoke family + notify), and a devices registry with per-device
+ admin revoke — the ACC-02 capability Supabase's own API couldn't provide.
## Definition of done
- [x] `trusted_devices` table (migration 0007, deny-by-default RLS + hash/family/user indexes)
- [x] `TrustedDeviceService` bridges the built `refresh.ts` engine to Postgres (hydrate→rotate→flush); issue/rotate/revokeFamily/listForUser/familyScope
- [x] OTP-verify `remember` → issue 30-day `__Host-jv-trust` cookie (HttpOnly/Secure/SameSite=Lax)
- [x] `POST /api/auth/trust/refresh` — rotate (reuse ⇒ revoke family + notify + clear cookie) → mint fresh Supabase session (skip OTP)
- [x] `/portal/login` auto-tries trust-refresh on load (skip OTP), falls back to email→code; "remember this device" checkbox
- [x] `GET /api/sessions` (self list) + `POST /api/sessions/[familyId]/revoke` (self OR admin-in-tenant); `/portal/devices` UI (TanStack Query, FEP-01)
- [x] Reuse notification (AUT-10) + `logError` on reuse
- [x] Live-verified E2E: remember → device listed → trust-refresh skips OTP → reuse → 401 + family revoked → explicit revoke (CSRF-gated) → 401
## Out of scope
Admin sessions UI (list/revoke across the tenant) → WP-034 (activity/admin screens; the API already supports admin revoke). Real reuse/notify email delivery → WP-028. A `Checkbox` component in the library (used a plain input here) → DSN candidate.

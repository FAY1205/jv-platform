# WP-004: Component library core
Spec: DSN-03..10 · Phase: 0 · Depends: WP-003 · Tier: B · Status: IN PROGRESS (preview slice)

## Goal
The one component library (nothing UI ships outside src/components), each
interactive component defining all states (default/hover/focus-visible/active/
disabled/loading), consuming tokens only.

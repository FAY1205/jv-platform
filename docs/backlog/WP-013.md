# WP-013: Real InvestorFuse Source Profile v1 + xlsx read (Web Worker)
Spec: ING-01/02/03/04/05/07/08, FEP-06, PRN-04, DM-02/08 · Phase: 1 · Tier: A · Depends: WP-010 (sources module), WP-008 (MLS engine)

## Goal
Replace the demo "Generic" placeholder with a real, versioned **InvestorFuse Source
Profile v1** (61-col signature; canonical mapping keyed on the **property** address/zip;
`notes → Notes` col 39 per the resolved open question), and add off-main-thread `.xlsx`
reading (SheetJS in a Web Worker, FEP-06) that yields `{ headers, rows }` for detection
and preview. No DB writes / no upload persistence yet — that is WP-017.

## Resolved decision (owner-confirmed 2026-07-07)
Canonical `notes` = **`Notes` (col 39) only**. `Comments` (col 40) carries call-logs +
seller PII and never the "is it listed?" signal → preserved in `raw_json` only (DM-02),
never in the MLS input or the export.

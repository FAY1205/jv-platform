# WP-005: DB schema + Drizzle + RLS + seeds + reference IDs
Spec: DM-01..11, SCP-01, SEC-01, PRN-05/07/08, API-04, SEAM-01 · Phase: 0 · Tier: A

## Goal
The full data model as code: all §5 tables (tenant-scoped), RLS on every table,
reference-ID allocation, and rules-as-data seeds — migration generates + typechecks
offline; applied to the cloud dev project when creds are available.

## Definition of done
- [x] Drizzle schema: all 20 §5 tables + `ref_counters`; `tenant_id` everywhere (SCP-01); DM-03 lead columns; DM-11 indexes
- [x] Enums, soft-delete (DM-09), coverage versioning (DM-06), append-only audit (DM-04), UTC timestamps (DM-05)
- [x] DDL migration generated (`0000_*.sql`); RLS + helpers + current-coverage unique index as a custom migration (`0001_*.sql`), same set (API-04)
- [x] RLS on every table (SEC-01); tenant isolation + partner scoping on leads (TST-01) + note-visibility on lead_notes (PRN-13/TST-08); claims-based helpers
- [x] Reference IDs (DM-07): `JV-###` / `LD-YYYY-#####` / `UP-YYYY-###`; `allocateRef` (transactional upsert) + pure format helpers (tested)
- [x] Seed (single-source, SEC-07 fake data): dev tenant, 9-partner roster + locked colors, state fallbacks (ASN-01), MLS patterns (WP-008), recodes, GENERIC source profile (WP-010), settings + flags defaults (PRN-11)
- [x] Server-only DB client (lazy; service role used only behind the scoping guard)
- [x] ADR-0003 (EU dev / US prod residency), ADR-0004 (tsx runner)

## Verification
- Now (offline): `pnpm run db:generate` → migration emits; `pnpm run check` → typecheck + tests green (incl. DM-07 ref-id formatting)
- When owner adds dev connection string to `.env.local`: `pnpm run db:migrate` applies schema + RLS; `pnpm run db:seed` loads seeds; smoke query works
- Full RLS/cross-tenant proof = WP-006 (TST-01)

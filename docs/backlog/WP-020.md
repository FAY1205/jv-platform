# WP-020: Upload flow — parse → process → results + download
Spec: ING-01/02/06, API-03, FEP-06, UXQ-02, EXP-05, PRN-08 · Phase: 1 · Tier: B*

## Goal
Close the loop to *usable*: drop a weekly file → parse it off the main thread → detect the
Source Profile → process through the spine → land on the run results with a colored-Excel download.

## Definition of done
- [x] Client worker parse (`src/lib/xlsx-client.ts` → `src/workers/xlsx.worker.ts`, FEP-06).
- [x] `/upload` page: drag-drop / browse, detected-format + row-count preview, honest step
      progress (UXQ-02: read → detect → process), error states; built from the component library.
- [x] `POST /api/uploads`: server detect (SEED profiles; exact auto-applies, else 409 — never
      silently guessed, ING-02/08), load tenant rules+coverage from DB (`loadRunRules`, PRN-08),
      `processRun` via `DrizzleRunStore` (advisory-locked, ING-06), DB-backed idempotency
      (`withDbIdempotency`, API-03). Zod-validated; uniform error envelope.
- [x] `GET /api/runs/[ref]/export`: regenerate the colored .xlsx from persisted leads (EXP-05
      blob storage deferred; the rules snapshot pins determinism). Download button on the results view.
- [x] "New run" entry from the runs index.

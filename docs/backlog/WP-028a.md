# WP-028a: Email digests + outbox + Resend (NTF-01/02/03)
Spec: NTF-01/02/03 · Phase: 2 · Tier: A · Depends: WP-020 (run/upload), dev-viewer (sink capture) · ADR-0011
## Goal
On each processed run, enqueue a per-partner **new-lead digest** (NTF-01, only partners
with new leads + an email) and an **admin run-summary** (NTF-02) into an **outbox**
table (NTF-03), then drain them through the `sendEmail` seam — Resend in production,
the SEC-07 sink/dev-viewer everywhere else — with delivery status + retry/backoff.
Storage/signed-URL exports (EXP-05, SEC-02/03) are the sibling WP-028b.

# WP-019/021: Run summary + leads/unmatched views (data-backed)
Spec: EXP-04, ASN-03, DED-02, FEP-01, PRN-08/14/15, DSN-03 · Phase: 1 · Tier: B

## Goal
Turn the approved routing-ledger spike into real, data-backed screens over persisted runs:
a runs index and a per-run results view (summary + distributed/removed/unmatched), all via
TanStack Query over a scoped API.

## Definition of done
- [x] Data layer: `@tanstack/react-query` (ADR-0008) + root `Providers`; components read from
      the query cache only (FEP-01).
- [x] Scoped API (PRN-08), uniform `{code,message,traceId}` errors (`src/lib/http.ts`):
      `GET /api/runs` (list), `GET /api/runs/[ref]` (summary + distribution + leads). Zod-validated.
- [x] `src/modules/run/queries.ts` — `listRuns` / `getRunDetail` through the scope guard;
      stats only from analytics (PRN-15); campaign recoded for display (EXP-01).
- [x] Phase-1 dev scope resolver (`src/lib/scope-context.ts`) → dev tenant admin (Phase-2 auth TODO).
- [x] `/runs` (index) + `/runs/[ref]` (results): summary tiles, partner-colored distribution bar +
      PartnerTag legend, distributed leads grouped by partner with the color rail (PRN-14), Removed
      (with matched MLS pattern) and Unmatched (state+ZIP, ASN-03) sections. Loading/empty/error states.
- [x] Verified live on the dev DB (run UP-2026-001: 50 leads → 24 delivered across 7 partners).

## Out of scope (→ later)
Sortable columns + debounced filters; server-side pagination + `@tanstack/react-virtual` for the
GLOBAL leads view (all history >200 rows, FEP-03); standalone `/leads` + `/unmatched` routes;
the upload flow that triggers a run (WP-020); void-run action (WP-018).

## Verification
`scripts/seed-sample-run.ts` (dev) persists a distributed run; `/runs` + `/runs/[ref]` render it
via the scoped API. `pnpm run check` + `build` green (181 unit tests).

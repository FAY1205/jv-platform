# WP-030: Partners CRUD + invite UI + deactivation → territory reassignment
Spec: ADM-03, PRN-05 (also PRN-06/14 color, DM-06/08 versioning+audit, ASN-02) · Phase: 2 · Tier: A · Depends: WP-023 (scope/auth), WP-025a (invite route)
## Goal
The admin manages the partner roster **in the app** (ADM-03): create with contact
details + locked color + JV-### ref-id, edit, invite/re-invite (existing route),
and **deactivate**. Deactivating a partner who still owns coverage ZIPs or state
rules prompts **reassignment to another partner** (new coverage version) **or
routing to Unmatched**; historical lead assignments are never touched (PRN-05),
and only future runs change. Simple per-partner lead count now; full stats tab → WP-029.

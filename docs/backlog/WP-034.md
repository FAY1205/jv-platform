# WP-034: Activity views (ACT-01/02/04)
Spec: ACT-01, ACT-02, ACT-04 · Phase: 2 · Tier: B · Depends: audit_log (all prior WPs write it)
## Goal

with security-relevant events highlighted (ACT-04). Partner activity view of the
partner's OWN actions on their OWN leads (status updates + notes), scoped (ACT-02).

# WP-016: Recode + Export renderer (EXP-01..06, SEC-06, PRN-14)
Spec: EXP-01/02/03/04/06, SEC-06, PRN-14/15, PRN-01 · Phase: 1 · Tier: A · Depends: WP-013/014/015

## Goal
Produce the weekly deliverable: campaign recode + a partner-grouped, color-coded `.xlsx`
with a fixed column contract, legend + summary sheets, formula-injection sanitization, and
a color ON/OFF toggle.

## Definition of done
- [ ] ADR-0007 — exceljs (write).
- [ ] `src/modules/pipeline/recode.ts`: `recode(campaign, rules) → code` (EXP-01) — trailing-`*`
      prefix match else exact, first rule wins, unmatched passes through. Pure.
- [ ] `src/modules/analytics/run-summary.ts`: pure `computeRunSummary(leads) → RunSummary`
      (total/kept/removed/unmatched/previously-matched + per-partner counts). SINGLE source of
      these numbers (PRN-15); WP-019 renders the same object on screen.
- [ ] `src/modules/export/render.ts`: `renderExport(leads, partners, summary, options) → Buffer`,
      deterministic. `EXPORT_COLUMNS` fixed-order seed (EXP-02, SEAM-03). Rows grouped by partner
      + `JV_Color_Legend` + `Run_Summary` sheets (EXP-03/04). Color ON = locked fills + AA text;
      OFF = bold group-header rows (EXP-06). Partner name + `JV-###` always present (PRN-14).
      Every user-originated cell sanitized (SEC-06).

## Out of scope
Persistence + signed-URL storage (EXP-05 → WP-017); the on-screen run-summary UI (WP-019);
the real golden diff (WP-022). If the renderer runs long, recode splits into its own WP.

## Tests
`tests/unit/recode.test.ts` · `tests/unit/run-summary.test.ts` · `tests/unit/export.test.ts`
(render→reload the workbook; assert EXP-02 column order, partner grouping, both extra sheets,
PRN-14 name+ref in row, SEC-06 sanitization of a `=`-prefixed cell, EXP-06 color-on fill vs
color-off bold header). Requirement-ID named.

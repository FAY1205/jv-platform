# WP-033: LinkOnly listing check (LST-01/02/03, SEAM-02)
Spec: LST-01/02/03, SEAM-02, PRN-09 · Phase: 2 · Tier: B · Depends: WP-020 (run), WP-026 (lead detail)
## Goal
A second, informational listing check — separate from the MLS filter. It runs after
the pipeline over a run's KEPT leads, flags each `pending → yes/no/unknown`, and
NEVER removes a lead (LST-03/PRN-09). The V1 provider is LinkOnly (SEAM-02): it can't
determine automatically, so it returns `unknown` + a verify link; an automated
provider drops in behind the same interface later.

# WP-002: Environment separation + non-prod email sink
Spec: SEC-07 · Phase: 0 · Depends: WP-001 · Tier: B

## Goal
A typed, validated environment config and an outbound-email guard so that
dev/preview code can never email real partners — the seam Phase 2's Resend
transport plugs into.

## Definition of done
- [x] `src/lib/env.ts` — Zod-validated env; APP_ENV ∈ {development,preview,production}; blank→unset
- [x] `isProduction` / `isNonProduction` helpers; admin allowlist parsing (SCP-02)
- [x] `src/modules/notify/email.ts` — `guardOutbound` redirects all recipients to the sink in non-prod; production passes through; `intendedTo` retained for audit
- [x] `EmailTransport` interface + `MemoryTransport` (Resend transport = Phase 2, NTF-03)
- [x] Tests: env defaults/validation; SEC-07 redirect in dev + preview; passthrough in prod; sendEmail never hands a real address to the transport in non-prod

## Verification (run)
- `pnpm run check` → typecheck + lint + tests green

## Out of scope (→ later WPs)
- ResendTransport + outbox table + delivery status/retry (Phase 2, NTF-03)
- Per-environment Supabase project wiring (needs cloud accounts; WP-005+)
- CSP/security headers (WP-007, SEC-04)

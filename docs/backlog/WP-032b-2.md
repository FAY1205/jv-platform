# WP-032b-2: Format-drift screen + versioned Source Profiles (ING-02/08, SET-12, DM-08)
Spec: ING-02, ING-08, SET-12, DM-08 · Phase: 2 · Tier: A · Depends: WP-032b-1, WP-020 (upload), sources module
## Goal
Never silently re-guess a changed format. A drifted or unknown upload returns a
diff + proposed mapping; the admin confirms → it's saved as a new/next Source
Profile VERSION (DM-08) and the run processes with it. Detection then reads the
tenant's saved versions + built-ins, so the same file matches exactly next time.
## Definition of done
- [x] `src/modules/sources/mapping.ts` — pure `suggestMapping` (follows renames / auto-maps by name), `missingRequiredFor`, `buildConfirmedProfile` (next version of base, or new v1)
- [x] `src/modules/sources/profile-store.ts` — `loadProfilesForDetection` (saved-latest-per-name ∪ seeds), `saveProfileVersion` (insert + audit `source_profile.saved`, DM-08), `listProfiles`, `findProfileById` (seed slug OR uuid — never queries the uuid column with a slug)
- [x] `src/modules/run/run-upload.ts` — extracted shared upload processing (pipeline + store export + digests/notifications + drain), used by the exact path AND the confirm path
- [x] `POST /api/uploads` — detects against saved+seed profiles; exact → process; drift/unknown → `{result:"needs_mapping", kind, diff, suggestedMapping, ...}`; genuinely-missing required → 422
- [x] `POST /api/uploads/confirm` — validates required, builds + saves the versioned profile, processes the run with it
- [x] `/upload` page — mapping/drift screen (column diff + per-field Select prefilled from the suggestion; unknown → name the format); Rules "File formats" shows saved versions
- [x] Live-verified: 3 integration tests (drift→confirm→v2→EXACT round-trip; unknown→new format→exact; findProfileById slug-safe); app E2E (drifted upload → needs_mapping → confirm saves v2 → re-upload auto-matches; unknown → needs_mapping)
- [x] Fixed: `findProfileById` queried the uuid `id` column with a seed slug ("investorfuse") → Postgres uuid-syntax error; now seed-first + uuid-guarded

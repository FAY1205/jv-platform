# WP-027: Two-stream notes (admin / partner, mutually invisible)
Spec: NTS-01/02/03, PRN-13, TST-08 · Phase: 2 · Tier: A · Depends: WP-006 (scope guard), WP-026
## Goal
Each lead has an admin note stream and a partner note stream that are mutually
invisible (PRN-13). Append-with-edit, edits audited (NTS-02). Partner notes on the
partner lead page; admin notes on a new admin lead page.
## Definition of done
- [x] `src/modules/notes/notes.ts` — `listLeadNotes` / `addLeadNote` / `editLeadNote`, all via `noteWhere` (author_role AND scope); edits audited to `audit_log` (before/after)
- [x] Shared API: `GET/POST /api/leads/[ref]/notes` · `PATCH /api/leads/[ref]/notes/[noteId]` (CSRF); scope decides the stream
- [x] `NotesPanel` component (TanStack Query; existing notes save on blur with a "Saved" indicator — NTS-02)
- [x] Partner notes on `/portal/leads/[ref]`; admin notes on new `/leads/[ref]` (admin-only); delivered leads in a run link to it
- [x] Proxy protects `/leads`
- [x] Live-verified: TST-08/PRN-13 (admin sees only admin notes, partner only partner notes; partner can't note another's lead; edit audited; partner can't edit an admin note)
## Out of scope (→ later)
NTS-03 export "JV Notes" column mapping (a setting; default blank) → settings area (WP/Phase-3). A `Textarea` primitive in the library (used a styled textarea) → DSN candidate. Admin lead page currently shows kept leads only (reuses the portal detail query).
